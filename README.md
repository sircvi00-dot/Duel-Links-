# Blue-Eyes Speed Duel Trainer

A personal practice app for a 20-card Blue-Eyes deck in Yu-Gi-Oh! Duel Links, with the Skill Destiny Draw: Blue-Eyed Dragons.

Tabs: Learn (short Speed Duel lessons), Watch (step-by-step best lines), Practice (pick the best move), Play (free play with rule checks, Undo, What now? and Best play), Deck (every card, its role, and its text).

Card images load from images.ygoprodeck.com and are cached for offline use after the first visit.
